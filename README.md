# Disha.co — Portfolio

A modern, responsive personal portfolio website for **Disha Deshmukh**, Full Stack Developer.

The portfolio showcases professional experience, technical skills, education, certifications, and software development projects.

## Features

- Responsive portfolio design
- Dark Mode / Light Mode
- Interactive hero section
- Professional experience showcase
- Technical skills section
- Project showcase with GitHub links
- Education and certifications
- Downloadable resume
- Email and phone contact
- LinkedIn and GitHub integration
- Smooth scroll and reveal animations
- Mobile-friendly navigation

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
